# HUSTCup · 校园足球模拟器

一款以华中科技大学校园足球联赛为背景的网页文字生涯模拟游戏。

当前版本：`v2.0`

玩家从大一新生开始，选择学院、号码和场上位置，在新生杯、华工杯、毕业杯三大赛事中经历训练、比赛、伤病、队内竞争和校园舆论，并选择读研、直博、读博、裁判、转专业、参军等不同人生路线，最终解锁不同的生涯结局。

## 访问量统计

初始录取通知书页面显示本游戏页面的累计访问次数，由[不蒜子](https://busuanzi.ibruce.info/)提供，无需配置数据库或密钥。

- 统计的是页面访问次数（PV），不是独立玩家人数；刷新页面也会计数，游戏内切换界面不会额外请求统计。
- 使用页面级 `page_pv`，避免混入同一 GitHub Pages 域名下其他项目的访问量；不同访问 URL 的计数可能不同，建议使用上方固定网址。
- 仅在正式域名 `fantasicrap.github.io` 加载统计脚本；本地运行和其他域名的预览不加载。迁移域名时需修改此判断。
- 数据由第三方统计服务维护，无法补回接入前未被记录的访问；加载中、离线或服务不可用时不显示计数，不影响游戏。

## 开局流程

1. 打开录取通知书，填写姓名。
2. 选择 1 至 99 的球衣号码。
3. 选择场上位置：前锋、中场、后卫或门将。
4. 从主校区 29 个学院和 6 个同济医学院相关学院中选择要加入的学院。
5. 查看随机天赋和初始能力后开始生涯。

学院分为甲组和乙组，甲组球队整体更强，但竞争也更激烈。

同济医学院相关学院包括基础医学院、法医学系、公共卫生学院、护理学院、药学院、医药卫生管理学院，全部属于同济组，参加华工杯同济医学院组。其中基础医学院、法医学系、公共卫生学院为五年制本科，护理学院、医药卫生管理学院为四年制本科，药学院在开学专业分流后确定学制。第一临床学院和第二临床学院不作为开局选项，只能由基础医学院学生在大三分流时进入。

## 核心数值

### 显性四维

| 数值 | 含义 |
|---|---|
| 能力值 | 个人球技与竞技水平 |
| 心态值 | 发挥稳定性、抗压能力和比赛状态 |
| 关系值 | 队内地位、教练信任和战术角色 |
| 学业值 | 学业状态，影响升学、考研、跨考和转专业 |

四维数值共同决定隐藏的“表现值”：

`表现值 = 能力×0.45 + 心态×0.25 + 关系×0.20 + 学业×0.10`

### 隐藏数值

- 潜力值：决定每年能力自然成长速度。
- 表现值：决定关键事件、赛事结果和最终结局。
- 联赛级别：甲组或乙组，可随成绩升降级。

数值较高时，成长和事件收益会逐渐衰减，避免后期四维全部溢出到 100。

## 校园赛事

### 新生杯

大一以球员身份参加；大三以后，如果担任队长，可以以新生队教练身份带队。

主校区 29 支球队与医学类 6 支球队共 35 支球队混合分组，每组前两名晋级淘汰赛，常规时间 60 分钟。医学类学院以本学院名义参赛。

### 华工杯

每年举办，分为甲组和乙组。

- 甲组成绩差的球队可能降入乙组。
- 乙组冠军和亚军升入甲组。
- 常规时间 80 分钟。

### 华工杯同济医学院组

同济医学院组共 8 支球队，分为两组，每组前两名出线，随后进行半决赛和决赛。

- 开局即可选择：基础医学院、法医学系、公共卫生学院、护理学院、药学院、医药卫生管理学院。
- 只能通过基础医学院大三分流进入：第一临床学院、第二临床学院。

直接选择医学类学院开局的玩家不需要分流，从大一学年起就以本学院身份参加同济医学院组比赛。基础医学院学生大一先参加新生杯，大二起以基础医学院身份参加同济医学院组，大三完成分流后按分流结果继续出战。

同济医学院组冠军获得“医学球王”成就。该组成绩不计入“全满贯”，会计入“双院名宿”。

医学类学院在新生杯、毕业杯中都以本学院名义参赛。只有通过基础医学院分流进入的第一临床学院、第二临床学院没有主校区身份，会以“基础医学院”的名义出战。

### 毕业杯

本科毕业或深造毕业前举办，赛制与新生杯类似。

淘汰赛常规时间打平后直接进入点球大战。

### 超级杯

每个学年开始时举办，由上赛季冠军参加：

1. 华工杯乙组冠军对阵同济医学院组冠军。
2. 第一场胜者对阵华工杯甲组冠军。
3. 最终胜者获得超级杯冠军和“最高荣誉”成就。

超级杯冠军计入“全满贯”和“双院名宿”。大一新生在满足条件时，也有机会在新生杯前被选中参加超级杯。

### 比赛方式

每场自己参加的比赛开始前，玩家可以选择：

- 我要决策：逐个处理比赛中的关键事件。
- 模拟比赛：系统自动随机处理全部事件，并给出最终比分和个人进球数。

比赛事件会影响比分和进球，不会直接修改四维数值。四维奖励由赛事结果统一结算。

### 赛事间歇事件

同一赛事的不同比赛之间，还可能触发校园日常抉择，例如：

- 学长约去野球场踢球
- 校园足球之夜看华工杯经典录像
- 院队德比前的赛前准备
- 战术录像课
- 临时加练
- 队内聚餐
- 雨战装备准备
- 学弟请教战术
- 新生球迷助威
- 家人电话
- 研究下个对手
- 赛前恢复
- 华工杯期间凌晨三点欧冠
- 非赛事期国家德比、双红会、曼市德比、伦敦德比
- 非赛事期欧洲超级杯、马德里德比、德国国家德比、意大利国家德比、米兰德比
- 2026年起每四年一次的世界杯观赛事件

校园间歇事件以校园生活为主；职业赛事观看事件只在华工杯期间或非赛事期随机出现。

熬夜看完球之后，如果本学年还有后续事件，下一个事件必定是“体能测试”或“晨训加练”；在这两个事件里选择“全力冲刺”或“咬牙坚持”，可以解锁成就“你跑不过我你信不信（记得爱惜自己）”。

## 生涯系统

### 队长系统

大二可以竞选队长。担任队长期间可以处理队内矛盾、组织招新、赛前动员等事件，并有机会连任。

### 裁判系统

可以加入足球协会成为裁判员，裁判等级严格按照以下顺序提升：

`无等级 → 三级 → 二级 → 一级`

裁判班会随机出现，并随机分配为校内班或校外班。二级和一级裁判班对能力值有体质要求。

### 医学分流

选择基础医学院开局的玩家：

- 大一以基础医学院身份参加新生杯；大二以基础医学院身份参加华工杯同济医学院组；大三完成分流后按分流结果出战。
- 大三完成医学分流，去向只有三个：第一临床学院、第二临床学院、基础医学院，三者可以自由选择，不设学业门槛。
- 基础医学院本科为五年制，升学抉择与毕业杯在医学大五触发；分流后的第一临床学院、第二临床学院同样是五年制。
- 新生杯和毕业杯以本学院名义参加主校区比赛；若分流进入第一临床学院或第二临床学院，则毕业杯以基础医学院名义出战。
- 医学分流使用独立选择页面。

直接选择法医学系、公共卫生学院、护理学院、药学院或医药卫生管理学院开局的玩家不需要分流，从大一学年起就以本学院身份参加华工杯同济医学院组比赛。

### 同济医学院组的课业

- 同济组学院的校园事件池更偏向学业，更容易出现能提升学业值的选项。
- 同济组的“高数考试”事件按年级替换成医科科目：大二考系统解剖学，大三考药理学，大四及以后在内科、外科、儿科、妇科中随机出现（四科平分该事件的出现概率）。
- 这些医科考试判定成功的概率降低 20%，并且不会低于 5%。
- 护理学院、医药卫生管理学院为四年制：升学抉择与毕业杯都在大四触发，不会出现医学大五的事件。
- 基础医学院、法医学系、公共卫生学院，以及分流后进入的第一临床学院、第二临床学院为五年制：升学抉择与毕业杯都在医学大五触发。

### 药学院专业分流

选择药学院开局的玩家，开学后会进行专业分流：

- 药学：四年制，升学抉择与毕业杯在大四触发。
- 临床药学：五年制，升学抉择与毕业杯在医学大五触发。
- 生物药学：四年制，升学抉择与毕业杯在大四触发。

分流不改变球队归属，各专业都继续代表药学院参加华工杯同济医学院组比赛。

### 升学和深造

普通本科生在大四触发升学抉择，医学生则延后到医学大五触发。

本科阶段可以选择：

- 保研外校
- 保研本校
- 考研
- 跨考
- 直接就业

保研选项要求学业值达到 85。学业 85 时保研成功率为 25%，学业 90 时达到 100%。

考研和跨考成功率受学业值影响。跨考成功后还会随机转入新的学院。

学业低于 90 时，挂科危机、学业警告、考试失利等事件会按概率分布出现；学业达到 90 后不再触发这些负面事件。学业超过 95 后还会触发国家奖学金评比。

### 转专业

大一和大二阶段可以参加转专业考试。

- 大一转专业：保留年级，从华工杯开始启用新学院身份。
- 大二转专业：降级回大一，总生涯延长一年。
- 转专业后清除当前队长身份，但保留裁判、服役、历史荣誉和个人数据。
- 医学类学院的学生可以转出到主校区普通学院。
- 医学分流后的学生可以降级转到主校区普通学院。
- 主校区普通学院不能转入医学类学院。

### 参军服役

大一或大二可以选择保留学籍服役两年。

- 服役结束返回原年级。
- 总生涯长度增加两年。
- 后续考研难度降低。

### 伤病与停赛

比赛中可能出现轻微、中度或重伤。受伤期间无法进入大名单，比赛自动模拟。

伤病会影响关系值和后续获得首发位置的概率。学年结束时，尚未痊愈的比赛伤病会自动恢复，不会影响下一学年的赛事。

战术犯规、危险放铲或与裁判争执可能吃牌。累计黄牌或红牌会导致停赛。

### 首发与替补

每年根据表现值和关系值决定下赛季是首发还是替补。替补的进球期望和对球队强度的影响较低，但可以通过加练、沟通或支持队友争取首发位置。

### 校内舆论

游戏包含两个舆论渠道：

- 校内球迷群
- HUSTFootball 官方公众号

比赛胜负、冠军荣誉、伤病和转专业都会产生舆论变化。球迷和官方关注度会影响后续事件和成就。

## 存档系统

游戏会在返回主界面时自动保存到当前浏览器。

- 重新打开游戏时可以“继续上次存档”。
- 存档只在当前浏览器和当前设备生效。
- 可以随时清除本机存档。

## 成就系统

成就面板区分三种状态：

- **本档已解锁**：彩色图标和金色高亮；本档达成后保持高亮。
- **历史已解锁**：灰色图标和名称；在本档再次达成后转为高亮。
- **尚未解锁**：问号，隐藏图标与名称。

面板分别显示本档和累计解锁数量，累计全成就登记仍包含历史荣誉。新开档不会把历史成就当成本档达成。旧版存档未记录解锁来源，升级时会保留全部历史荣誉，并将能从当前数据确认达成的项目标为本档解锁。

## 结局系统

游戏根据最终路径、数值、荣誉和特殊经历匹配结局，包括：

- 普通本科结局
- 深造结局
- 裁判结局
- 隐藏结局

最终结局由优先级从上到下匹配，玩家可以通过不同选择体验不同人生路线。

## 回归测试

安装 Node.js 22 或更新版本后，在项目目录执行：

```sh
node --test tests/regressions.test.cjs
```

测试直接运行页面内的游戏脚本，覆盖存档迁移、生涯学制、赛事资格、事件队列和全成就登记工作流；无需安装 npm 依赖。测试使用独立的内存存档，不会修改浏览器中的玩家存档。
